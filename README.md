🚀 Project Overview: Neural Vault
Neural Vault is an advanced career path forecasting system designed to bridge the gap between academic performance and professional goal-setting. Unlike traditional ERPs, it acts as an Intelligence Hub that analyzes multi-semester data points to provide data-driven career recommendations.

🧠 Core Features:
Predictive Analytics: Implements a Random Forest-based logic to identify core competencies from subject-specific marks.

Neural Dashboard: A dark-themed, high-fidelity UI for students to visualize their academic trajectory.

Bulk Sync: Admin-side CSV synchronization with automated GPA and Status (Pass/Fail/Absent) calculation.

Secure Repository: A robust backend architecture for storing and managing encrypted academic records.

🛠 Technical Stack:
Backend: Python (Flask)

Database: MySQL (Relational Schema for High Data Integrity)

Frontend: HTML5, CSS3 (Cyber-grid Theme), Bootstrap 5, Animate.css

Algorithm: Random Forest (Ensemble Learning Logic)
